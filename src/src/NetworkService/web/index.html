Network settings

Reading Wi-Fi settings…

Saving restarts the adapter and briefly disconnects USB. A blank password keeps the saved password for the same network. A different network needs its own password, or the explicit no-password setting. After a successful home-network connection, the adapter disables its own access point and you must reconnect using the router IP or local name. Its recovery access point automatically returns if home Wi-Fi stays unavailable. To use only the adapter's Wi-Fi, turn off joining or forget the network.

OLED display

Checking…

0.91-inch SSD1306 · 128×32 · I²C1 on GP14 / GP15. Settings apply without reboot; Save writes them to the adapter for future boots.

Reading OLED settings…

Display behavior

The startup mark gives way to network address, active profile, USB/remote status, and Wi-Fi screens. When a controller connects, an extra Bluetooth or wired USB page shows its controller family. Save, apply, and firmware operations temporarily interrupt the rotation with status glyphs and progress.

Idle timeouts reset on meaningful state changes and display-setting edits. Screen off uses the SSD1306 display-off command; it does not remove power from the OLED module. A later activity event wakes it.

Brightness is SSD1306 contrast, not a backlight adjustment. Inverted and rotated modes apply immediately.

Enter Configuration mode to modify OLED settings while console input is neutral.

Enter Configuration to upload or install firmware while USB input stays neutral.

Build your board's preset in VS Code and select the generated .ogxw update package. Uploading stages and checks it before installation.

Reading updater status…

Controller input pauses during updates. Keep power connected during installation. If power is lost during the final flash copy, recover using BOOTSEL and the UF2 file. This updater does not provide automatic rollback.
