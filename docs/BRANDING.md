# DarkoneCustoms / DC-OGX-W visual identity

The **DXC** symbol is a condensed DarkoneCustoms mark joined by an X-like gamepad motif. The primary palette is charcoal, metallic white and vivid green; the OLED interpretation is monochrome for the SSD1306.

The individual assets in [`assets/branding/`](../assets/branding/) are derived from the accepted project concept. Use these ready-to-use variants:

| File | Intended use |
|---|---|
| `emblem.png` | Large product/repository emblem with circuit details |
| `wordmark.png` | Project-name wordmark |
| `horizontal-lockup.png` | Compact horizontal arrangement for websites and docs |
| `icon.png`, `web-icon-90.png`, `favicon-64.png` | Square app/device icons, WebUI header, browser tab |
| `monochrome-lockup.png` | Single-color use |
| `oled-glyph-dxc-64x24.png` | Pixel-optimized SSD1306 mark (64×24) |
| `splash-artwork-16x9.png` | Desktop/repository promo and boot-splash art concept |
| `repo-banner.jpg` | Optimized GitHub README banner |
| `brand-concept-source.png` | Source concept sheet retained for future revisions |

The animated or colored desktop splash artwork **cannot** be displayed directly on the 128×32 monochrome OLED; the device intentionally uses the simplified bitmap rather than truncating a 16:9 composition.

For a future enclosure, packaging or Windows client, prefer the compact icon and matching wordmark. Use source assets rather than crops from README screenshots. These are raster derivatives of concept artwork, not editable vector master files.

The `concepts/` subfolder is visual reference only, not product documentation.
